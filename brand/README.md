# ishubhamx brand

**Launch X.** The mark is the **x** of ishubhamx. One arm is an arrow that rises from a gold start dot and passes over the other arm: the start of an idea, launched.

| File | Use it for |
|---|---|
| `mark.svg`, `png/mark-{1024,512,192}.png` | Primary logo: rounded night badge |
| `avatar.svg`, `png/avatar-1024.png` | Profile pictures that get cropped to a circle (GitHub, Google, X, LinkedIn, Play developer page) |
| `lockup-on-dark.svg`, `png/lockup-on-dark.png` | Badge + wordmark on dark backgrounds |
| `lockup-on-light.svg`, `png/lockup-on-light.png` | Badge + wordmark on light backgrounds |
| `glyph.svg`, `png/glyph-{white,black}-512.png` | One-colour mark on a transparent background, for watermarks, stamps and print (`glyph.svg` uses `currentColor`) |
| `og-image.png` | 1200×630 social share card |
| `png/apple-touch-icon.png`, `png/favicon-32.png`, `/favicon.ico` | Browser and home-screen icons |

Hosted at `https://ishubhamx.github.io/brand/<file>`.

## Type

Wordmark and headings: **Bricolage Grotesque** ExtraBold (800). Body text: **Inter**. Both are free on Google Fonts. The wordmark in the SVGs is outlined, so it renders correctly without the font installed.

## Rules

- Keep clear space around the logo of at least a quarter of the badge's width.
- Don't recolour the badge, stretch it, rotate it, or flip the arrow; it always points up and to the right.
- The arrow always crosses over the other arm. In one colour, keep the gap at the crossing.
- Smallest sizes: badge 16px, lockup 120px wide.
